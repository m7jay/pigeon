This sends a synthetic test event.

It is not a dry run and it is not a simulation. It is a real event that travels the production path: validated against the event type's own schema, fanned out to the endpoints that match, retried and logged exactly like any other delivery. It is marked as a test everywhere it appears - in this portal's delivery log and event page, and in the consumer's own view - so nobody mistakes it for customer traffic. The only thing the marker changes is how it is labelled.
